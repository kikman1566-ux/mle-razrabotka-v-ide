# DataFrameReporter

Проект содержит класс `DataFrameReporter` для первичной диагностики датафреймов pandas.

Класс позволяет получить основную информацию о данных:
- количество строк и столбцов;
- количество и долю дубликатов;
- сводную статистику;
- количество и долю пропущенных значений.
